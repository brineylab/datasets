# datasets

The lab's datasets: a recipe per dataset in this repository, the files as versions on the Hugging Face Hub, and one prose skill per dataset that people and their agents both read. Nothing here is flyloft-specific; flyloft is one user and one contributor.

This repository is being built by [docs/plans/datasets-a.md](docs/plans/datasets-a.md). Its vision is [docs/VISION.md](docs/VISION.md) and its design [docs/DESIGN.md](docs/DESIGN.md). The plan's Task 1 replaces this README with the real one: finding a dataset, reading it from anywhere, and installing the skills.
