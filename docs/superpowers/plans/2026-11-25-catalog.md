# CI-generated `CATALOG.md` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically generate and maintain `CATALOG.md` at the repository root from `datasets/*/SKILL.md` frontmatter and `results/<name>/<version>.txt` on every push to `main`, and point `README.md`, `AGENTS.md`, and `CONTRIBUTING.md` at it.

**Architecture:** A standalone stdlib Python script (`scripts/catalog.py`) reuses `scripts/check.py` to parse skills, records, and `hub.toml`, rendering a 7-column Markdown table for every published dataset. A dedicated GitHub Actions workflow (`.github/workflows/catalog.yml`) runs on `push` to `main` (and `workflow_dispatch`) with `permissions: contents: write`, leaving `.github/workflows/datasets.yml` strictly read-only for PRs.

**Tech Stack:** Python 3.8+ standard library (`python3 -I`), `unittest`, GitHub Actions (`actions/checkout@v7`).

**Spec:** `docs/superpowers/specs/2026-11-25-catalog-design.md`

## Global Constraints

- `scripts/catalog.py` runs on Python 3.8+ with the standard library alone (`python3 -I`).
- Nothing in `scripts/` or `.github/` hardcodes `brineylab`; the Hub org comes from `hub.toml`.
- `.github/workflows/datasets.yml` stays untouched (`permissions: contents: read`).
- `docs/VISION.md` and `docs/DESIGN.md` are not edited.
- Dataset PRs must pass `python3 -I -m unittest discover tests` without editing `CATALOG.md` (tests must not compare live `CATALOG.md` bytes to `render_catalog(ROOT)`).
- Commit messages are one sentence stating the behavior.

## Review Focus

1. **Pipes or newlines in `description`:** must collapse whitespace/newlines and escape `|` as `\|` so Markdown rows never break (pinned in Task 1).
2. **Missing, failing (`exit != 0`), or older-version-only record:** dataset must be omitted from `CATALOG.md`, never crashing or falling back to an older version (pinned in Task 1).
3. **Missing optional `metadata.count`/`metadata.unit`, or passing record with zero `file` lines:** must render `—` in `Entries` / `Size` (pinned in Task 1).
4. **Rounding boundaries (`999_950` entries or bytes):** must promote to `1.00M` / `1.00 MB` instead of emitting `1000k` / `1000 KB` (pinned in Task 1).
5. **Fork with a custom `hub.toml` org and stray non-directory files under `datasets/`:** links and `snapshot_download` hint must use `root/hub.toml`'s `org`, non-directories under `datasets/` must be ignored, and `.github/workflows/catalog.yml` / `scripts/catalog.py` must not name `brineylab` (pinned in Tasks 1 & 2).

## File Structure

- Create `scripts/catalog.py`: stdlib generator (`format_count`, `format_bytes`, `escape_cell`, `render_catalog`, CLI `main`).
- Create `tests/test_catalog.py`: unit tests for formatting, escaping, filtering, org-agnosticism, CLI, live repo rendering, and workflow invariants.
- Create `.github/workflows/catalog.yml`: `push` to `main` + `workflow_dispatch` workflow updating `CATALOG.md`.
- Create `CATALOG.md`: initial generated catalog at repo root.
- Modify `README.md:7-10`: point `## Finding a dataset` at `CATALOG.md` and its raw GitHub URL.
- Modify `AGENTS.md:16-39`, `AGENTS.md:53-59`: document `CATALOG.md`, `scripts/catalog.py`, and `.github/workflows/catalog.yml`.
- Modify `CONTRIBUTING.md:103-115`: note that `CATALOG.md` is updated by CI on `main` and not edited in PRs.

```python
import shutil, subprocess, sys, tempfile, unittest
from pathlib import Path
from helpers import ROOT
import check  # noqa: E402
import catalog  # noqa: E402


class CatalogTests(unittest.TestCase):
    def test_format_count_and_bytes_handle_scales_and_rounding_boundaries(self):
        self.assertEqual(catalog.format_count(300, "pairs"), "300 pairs")
        self.assertEqual(catalog.format_count(22866, "structures"), "22.9k structures")
        self.assertEqual(catalog.format_count(542378, "structures"), "542k structures")
        self.assertEqual(catalog.format_count(1186496, "pairs"), "1.19M pairs")
        self.assertEqual(catalog.format_count(299748717, "sequences"), "300M sequences")
        self.assertEqual(catalog.format_count(999950, "rows"), "1.00M rows")
        self.assertEqual(catalog.format_bytes(0), "0 B")
        self.assertEqual(catalog.format_bytes(999), "999 B")
        self.assertEqual(catalog.format_bytes(48252), "48.3 KB")
        self.assertEqual(catalog.format_bytes(999950), "1.00 MB")
        self.assertEqual(catalog.format_bytes(1518620607), "1.52 GB")
        self.assertEqual(catalog.format_bytes(120558318035), "121 GB")

    def test_escape_cell_collapses_newlines_and_escapes_pipes(self):
        self.assertEqual(catalog.escape_cell("a | b\n  c\t|d"), r"a \| b c \|d")

    def test_render_catalog_filters_unpublished_uses_hub_org_and_handles_missing_optional_fields(self):
        tmp = Path(tempfile.mkdtemp()); self.addCleanup(shutil.rmtree, tmp)
        (tmp / "hub.toml").write_text('org = "exampleorg"\ntoolshed = "ghcr.io/exampleorg/toolshed"\n')
        (tmp / "datasets").mkdir(); (tmp / "datasets" / ".DS_Store").write_text("junk")
        def add_ds(name, version, desc, extra="", rec_version=None, rec_exit=0, files=()):
            d = tmp / "datasets" / name; d.mkdir(parents=True)
            (d / "SKILL.md").write_text(f"---\nname: {name}\ndescription: \"{desc}\"\nmetadata:\n  version: {version}\n  tools: datascience@1.2.0\n  license: mit\n{extra}---\n")
            if rec_version is not None:
                r = tmp / "results" / name; r.mkdir(parents=True)
                manifest = "".join(f"file {p} {sz} {'0' * 64}\n" for p, sz in files)
                (r / f"{rec_version}.txt").write_text(f"---\ndataset: {name}\nversion: {rec_version}\nexit: {rec_exit}\n---\n{manifest}")
        add_ds("beta", "1.0.0", "No count or files.", rec_version="1.0.0")
        add_ds("alpha", "1.2.0", "A | B   extra spaces.", "  count: 1500\n  unit: pairs\n", rec_version="1.2.0", files=[("a.parquet", 2048)])
        add_ds("gamma", "1.0.0", "Failed build.", rec_version="1.0.0", rec_exit=1)
        add_ds("delta", "1.0.0", "Missing record.")
        add_ds("epsilon", "2.0.0", "Only old record.", rec_version="1.0.0")
        out = catalog.render_catalog(tmp)
        self.assertIn("2 published datasets.", out)
        self.assertIn('`snapshot_download("exampleorg/<name>", repo_type="dataset", revision="v<version>")`', out)
        rows = [l for l in out.splitlines() if l.startswith("| [")]
        self.assertEqual(rows, [
            r"| [alpha](datasets/alpha/SKILL.md) | [v1.2.0](https://huggingface.co/datasets/exampleorg/alpha/tree/v1.2.0) | 1.50k pairs | 2.05 KB | mit | datascience@1.2.0 | A \| B extra spaces. |",
            "| [beta](datasets/beta/SKILL.md) | [v1.0.0](https://huggingface.co/datasets/exampleorg/beta/tree/v1.0.0) | — | — | mit | datascience@1.2.0 | No count or files. |",
        ])

    def test_cli_stdout_and_write_flag(self):
        tmp = Path(tempfile.mkdtemp()); self.addCleanup(shutil.rmtree, tmp)
        (tmp / "hub.toml").write_text('org = "exampleorg"\ntoolshed = "ghcr.io/exampleorg/toolshed"\n')
        (tmp / "datasets" / "one").mkdir(parents=True)
        (tmp / "datasets" / "one" / "SKILL.md").write_text("---\nname: one\ndescription: \"One dataset.\"\nmetadata:\n  version: 1.0.0\n  tools: datascience@1.0.0\n  license: mit\n---\n")
        (tmp / "results" / "one").mkdir(parents=True)
        (tmp / "results" / "one" / "1.0.0.txt").write_text("---\ndataset: one\nversion: 1.0.0\nexit: 0\n---\n")
        r1 = subprocess.run([sys.executable, "-I", str(ROOT / "scripts" / "catalog.py"), "--root", str(tmp)], capture_output=True, text=True, check=True)
        self.assertEqual(r1.stdout, catalog.render_catalog(tmp))
        self.assertIn("1 published dataset.", r1.stdout)
        subprocess.run([sys.executable, "-I", str(ROOT / "scripts" / "catalog.py"), "--root", str(tmp), "--write"], check=True)
        self.assertEqual((tmp / "CATALOG.md").read_text(encoding="utf-8"), r1.stdout)

    def test_live_repo_renders_every_published_dataset(self):
        out = catalog.render_catalog(ROOT)
        expected = [
            d.name for d in sorted((ROOT / "datasets").iterdir())
            if d.is_dir() and (d / "SKILL.md").is_file()
            and (rec := ROOT / "results" / d.name / f"{check.frontmatter(d / 'SKILL.md')['metadata']['version']}.txt").is_file()
            and check.parse_record(rec)["exit"] == 0
        ]
        rows = [line for line in out.splitlines() if line.startswith("| [")]
        self.assertEqual(len(rows), len(expected))
        for name, row in zip(expected, rows):
            self.assertIn(f"[{name}](datasets/{name}/SKILL.md)", row)
            self.assertEqual(row.replace(r"\|", "").count("|"), 8)  # 7 columns
```

- [ ] **Step 3: Implement `scripts/catalog.py`**

Create `scripts/catalog.py` (stdlib-only, Python 3.8+, `from __future__ import annotations`, imports `check` from `Path(__file__).resolve().parent`):
- Shared helper `_compact(value: int, units: tuple[str, ...], sep: str = "") -> str`: for `value < 1000`, returns `f"{value}{sep}{units[0]}"`; otherwise scales by `1000` with 3 significant digits (`< 10`: `.2f`, `< 100`: `.1f`, `>= 100`: `.0f`), stepping up one unit when rounding hits `1000.0` (so `999_950` renders `1.00M` / `1.00 MB`).
- `format_count(count: int, unit: str) -> str`: `f"{_compact(count, ('', 'k', 'M', 'B', 'T'))} {unit}"`.
- `format_bytes(size: int) -> str`: `_compact(size, ("B", "KB", "MB", "GB", "TB"), sep=" ")`.
- `escape_cell(text: str) -> str`: collapses runs of whitespace/newlines to single spaces and replaces `|` with `\|`.
- `render_catalog(root: Path = check.ROOT) -> str`:
  - Reads `org = check.read_toml((root / "hub.toml").read_text(encoding="utf-8"))["org"]`.
  - Scans `sorted((root / "datasets").iterdir())` skipping non-directories; reads `SKILL.md` frontmatter via `check.frontmatter`; skips if `metadata` isn't a dict or `version` is empty; reads `results/<name>/<version>.txt` via `check.parse_record` and skips if missing or `exit != 0`.
  - Formats each row:
    - `Dataset`: `[{name}](datasets/{name}/SKILL.md)`
    - `Version`: `[v{version}](https://huggingface.co/datasets/{org}/{name}/tree/v{version})`
    - `Entries`: `format_count(int(count), unit)` when `count.isdigit()` and `unit`, else `"—"`
    - `Size`: `format_bytes(sum(size for _, size, _ in rec["files"]))` when `rec["files"]` non-empty, else `"—"`
    - `License`, `Tools`, `Description`: `escape_cell(...)` (using `"—"` if empty).
  - Emits exact header and table ending with a trailing newline:
    ```markdown
    # Dataset Catalog

    <!-- Auto-generated by scripts/catalog.py. Do not edit by hand. -->

    <N> published dataset[s]. Read any version with:
    `snapshot_download("<org>/<name>", repo_type="dataset", revision="v<version>")`

    | Dataset | Version | Entries | Size | License | Tools | Description |
    | --- | --- | --- | --- | --- | --- | --- |
    ```
- `main(argv: list[str] | None = None) -> int`: parses `--write` and `--root` (default `check.ROOT`); writes `root / "CATALOG.md"` (UTF-8) with `--write` or prints `render_catalog(root)` to stdout (`end=""`).
